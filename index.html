03 Chapter Findings log

I attack my own code.

An audit of my own projects. Every issue below is patched and has a regression test.

HIGH

JWT token forgeryLibra · auth

A hard-coded fallback secret meant anyone could sign an admin token if the env var was missing. Fix: fallback removed, and production refuses to start without a strong secret.

HIGH

Stored XSSLibra · catalog

Two book fields reached the page unescaped, so a librarian could run script in an admin's browser. Fix: server-side validation, output escaping and a CSP.

MED

Unhandled async crashConsignly · API

A malformed ID caused a rejected promise that killed the Node process. Fix: every async route is wrapped and returns a 4xx error.

MED

Stale role after suspensionRBAC

Roles came from the token, so a suspended user kept access until it expired. Fix: the user is re-read from the database on every request.

HARDEN

Brute force and injectionboth apps

Auth routes are rate-limited, Helmet sets security headers, and all 72 SQL queries in Libra are parameterized.
