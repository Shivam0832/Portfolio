# Shivam Shinde · Portfolio

**Live:** https://shivam0832.github.io/Portfolio/

A scroll-driven 3D portfolio. One WebGL particle field (about 14,000 points) morphs through seven chapters (globe, thread, terrain, padlock, stack, badge, tunnel) while the story scrolls over it.

- **Work:** ThreatWeave, MedStore, AgriSetu AI, QuantLab, Consignly, Libra
- **Findings log:** security bugs I found and fixed in my own code
- **Live terminal:** try `help`, `projects`, `sudo hire-me`, `matrix`
- **Easter egg:** ↑ ↑ ↓ ↓ ← → ← → B A

Built with Three.js (bloom + custom glitch shader), Lenis smooth scroll and Web Audio (sound is off until you turn it on). A single `index.html` with no build step, served by GitHub Pages.

Respects `prefers-reduced-motion`, and works on phones.
